# Кекстаграм

**JavaScript · HTML · CSS · Fetch API · Vite · Pristine · noUiSlider**
Учебный проект HTML Academy

Фотогалерея с фильтрами, просмотром комментариев и редактором изображения перед публикацией. Проект объединяет работу с DOM, асинхронные запросы, валидацию формы и управление состоянием модальных окон.

## Подход к разработке

- **Работа с API:** получение JSON и отправку формы через FormData.
- **Обработка состояний:** сообщения об успехе и ошибке, блокировку отправки на время запроса, сохранение введенных данных при ошибке.
- **Валидация:** ограничения количества и длины хэштегов, проверку дубликатов без учета регистра и длины комментария.
- **Интерактивный UI:** модальные окна, порционный вывод комментариев, масштаб и эффекты изображения.
- **Организация JavaScript:** отдельные модули для запросов, отображения, фильтров и формы.

## Технологии

- HTML, CSS, JavaScript и ES modules;
- DOM API, Fetch API, FormData;
- Vite;
- Pristine для проверки полей;
- noUiSlider для интенсивности эффектов;
- ESLint.

## Реализованные возможности

- Загрузка фотографий с учебного API и вывод карточек галереи.
- Фильтры: исходный порядок, случайная выборка и сортировка по числу комментариев.
- Просмотр большой фотографии с выводом комментариев порциями по пять.
- Закрытие модальных окон кнопкой, Escape и кликом вне содержимого.
- Выбор изображения и предпросмотр в форме загрузки.
- Изменение масштаба от 25% до 100% с шагом 25%.
- Выбор эффекта и настройка интенсивности.
- Проверка количества, формата и уникальности хэштегов; ограничение длины комментария.
- Отправка формы, блокировка кнопки на время запроса и отображение результата.

## Структура

```text

```

## Локальный запуск

Скачайте исходники, распакуйте их и откройте терминал в корне проекта.

```bash
npm ci
npm run start
```

Vite запускает приложение на порту 3000 и открывает браузер. Галерея получает данные из учебного API.

Проверка JavaScript линтером:

```bash
npm run lint
```

## Область проекта

Реализованы просмотр галереи и комментариев, редактирование изображения и отправка формы. Постановка лайков и публикация комментариев к чужим фотографиям остаются элементами макета.
